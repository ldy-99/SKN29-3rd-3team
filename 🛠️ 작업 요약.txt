💡 해결 방법: 접속 주소를 127.0.0.1로 통일하기
현재 프론트엔드와 백엔드가 서로 다른 도메인명으로 통신하고 있을 수 있습니다.

백엔드 API 주소: http://127.0.0.1:8000 (IP 주소)
프론트엔드 브라우저 접속 주소: http://localhost:5173 (localhost 도메인)
브라우저는 localhost와 127.0.0.1을 서로 완전히 다른 주소로 인식하기 때문에, 백엔드에서 발급한 로그인 세션 쿠키를 브라우저가 저장하지 않거나 거부합니다. 이 때문에 로그인 API 호출은 성공하더라도, 직후 프로필 화면으로 이동하자마자 **"로그인이 되어 있지 않다(401 Unauthorized)"**고 판단하여 다시 로그인 화면으로 팅겨 보내는 현상이 발생합니다.
